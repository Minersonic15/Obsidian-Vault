# Resolution of Vectors
- Consider a generalise vector A
- We can break it into its horizontal (x-component Ax) and vertical (y-component Ay)
- We can ask sketch in an angle between horizontal and vector A
# What is component method
- the graphical method is efficient for co linear vectors and vector problems with 2 vectors only
- If there are more than two, it is easier and more efficient to use component method
- Comp method resolves each vector into x component and y component
- resultant is then calculated through addition of these components
