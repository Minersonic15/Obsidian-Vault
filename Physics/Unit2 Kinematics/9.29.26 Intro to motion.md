Mechanics
- branch of physics which concerns about forces and how they affect body's motion
Kinematics
- Sub-branch of mechanics which studies only a body's motion without regard to causes
Dynamic
- Sub-ranch of mechs which studies forces which causes body's motion

# What is Motion
- an objects change in position relative to a ref point
- eg:
	- Although we relative to earth, we moving 100,000kmph to the sun
	- F1 car reaching 360kmph

# Speed vs Velocity
- Speed is distance over time
- Velocity is speed over time
# Distance vs Displacement

| Distance                          | Displacement                            |
| --------------------------------- | --------------------------------------- |
| Scalar                            | Vector                                  |
| How far travelled                 | How far from origin                     |
| s = total length of path followed | s-> = final position - initial position |
