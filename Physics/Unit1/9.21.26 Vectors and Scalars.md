# Vectors & Direction
To state direction of a vector we can use two systems
- Compass System:
	- Most preferred method of stating dir
	- N30E > Start North, rotate 30 east
		- Same direction from the yeast?
- Rectangular Coordinate System (RCS)
	- Like meth, 0 degs corresponds to positive X axis
	- As rotate CCW, increase angle
- Can be represented as an arrow of scale length
- No "requirement" that a vector must lie on either x or y axis
	- It can be any dir
