# Binary Ionic Compounds
[[10.8.26 Ionic Nomenclature]]
- Criss-cross rule
	- Write symbols of 2 elements (metal first)
	- Place valence of each element on top of each symbol
	- criss-cross numbers to opposite element
	- This is to choose the right num of each element
# Multivalent Metals
- Charges on metals
	- Use roman numeral in the name, indicate s which charge is used
	- Use criss cross rule

# Oxyacids
[[10.9.26 Covalent Compounds]]
When enough hydrogen is added to balance charge of polyatomic ion with oxygen, the ion is converted to acid using criss-cross rule
- "-ic acids"
	- Ions that end in "ate"
- "-ous acids"
	- Ions and in "ite"(bold because newer)

I **ate** something **ic**ky
I took a b**ite** of something delici**ous**
# Binary Acids
Start with H
- H + non-metal
	- Hydro___ic acid (Bindary)
- H + polyatomic ion
	- -ate = -ic acid
	- -ite = -ous acid
