 # Binary Compounds
- 2 elements
- Ending of second element (e- acceptor, anion) [[9.16.26 Ions]] changed to -ide
- Criss-cross rule
	- Write symbols of 2 elements (metal first)
	- Place valence of each element on top of each symbol
	- criss-cross numbers to opposite element
	- This is to choose the right num of each element
- e.g:
	- Ca(2+) P(3)
	- Ca3P2
	- Calcium phosphide
# Transition metals -IUPAC
- International Union of Pure and applied chemistry
- Metal with 2+ valences
- Roman numerals used for first element (metal) only
	- found in [[Chemistry data Booklet]]
- Naming:
	- Roman numerals indicate which avlence is being used
- Writing
	- reverse criss-cross
- e.g:
	- Iron(III) Sulfide(2-)
	- Fe2S3
# Polyatomic ions

- Usually contains oxygen
- Use brackets if more than one polyatomic ion in formula
