# Rules
- If first element is singular, don't put Mono
	- still put for second tho
- If second element is oxygen, remove A or O before oxide
- Do not reduce subscripts, keep number given
# Oxyacids
When enough hydrogen is added to balance charge of polyatomic ion with oxygen, the ion is converted to acid using criss-cross rule
- "-ic acids"
	- Ions that end in "ate"
- "-ous acids"
	- Ions and in "ite"(bold because newer)

I **ate** something **ic**ky
I took a b**ite** of something delici**ous**

e.g.
Iodic acids = HIO3
Nitric acid = HNO3
Acetic acid = HC2H3O2
Sulfurous acid = H2SO3
# Binary Acids
- 2 elements
	- H and non-metal
- HCl = hydro**chlor**ic acid
- HF = hydroflouric acid
- HI = Hydroiodic acid

Start with H
- H + non-metal
	- Hydro___ic acid
- H + polyatomic ion [[10.8.26 Ionic Nomenclature]]
	- -ate = -ic acid
	- -ite = -ous acid
